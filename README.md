# 🚀 Youth Hub

Youth Hub is a student-focused web platform that brings
study resources, useful tools, games, and skill-development
resources together in one place.

## 🌐 Live Website

Coming soon — hosted on Vercel.

## ✨ Features

- 🔐 Sign Up and Login interface
- 👋 Personalized user welcome
- 🚪 Logout functionality
- 🔒 Basic frontend login protection
- 🔍 Search functionality
- 🎓 Study resources
- 🛠️ Useful tools
- 🎮 Games
- 💻 Skill development resources
- 📱 Responsive website design
- ⚡ Fast and lightweight frontend
